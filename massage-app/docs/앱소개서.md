# CallGuard (콜가드)

### 업주를 위한 스마트 전화 & 업무지원 앱

---

## 이런 경험, 있으시죠?

- 처음 보는 번호로 전화가 왔는데... **블랙 상습범**이었다
- 진상 고객인지 모르고 예약 잡았다가 **피해**를 봤다
- 같은 번호가 여러 업소에서 **콜폭**을 했는데 알 방법이 없었다
- 타업소 사장이나 직원이 전화했는데 **누군지 몰라서** 당했다
- 관리사 출근부를 **매일 수작업**으로 채널에 올리고 있다
- 예약을 **머릿속이나 메모장**에 기록하고 있다
- 예약 장부가 남아서 **부담**이 된다

---

## 콜가드가 해결합니다

### 1. 전화가 오면 바로 알 수 있습니다

콜가드를 기본 전화앱으로 설정하면, 전화가 올 때 **다른 업주들이 등록한 고객 정보**가 바로 표시됩니다.

> "이 번호는 **3개 업소**에서 등록됨 | **블랙 2회** | 진상"

모르는 번호도 더 이상 불안하지 않습니다.

### 2. 업주들이 함께 만드는 고객 데이터베이스

콜가드 사용자들은 고객 정보를 **서로 공유**합니다.
- 블랙, 진상, 콜폭, 타업소 등 **태그**로 빠르게 확인
- 각 업소가 남긴 **메모**를 통해 상세 이력 파악
- 내가 겪은 문제 고객을 등록하면 **다른 업주도 보호**됩니다
- 타업소 사장/직원도 등록 가능 — 누구인지 미리 알 수 있습니다

### 3. 전화 한 통으로 예약까지

통화가 끝나면 최근기록에서 바로 **예약 등록**:
1. 번호 탭
2. 관리사 선택 (현재 가용한 관리사만 표시)
3. 시간 + 코스 선택
4. 완료

별도 앱이나 메모장 필요 없이 **전화 → 예약**을 한 번에.

### 4. 관리사 & 출근부 관리

- 관리사 사진, 정보 등록
- **출근/퇴근 원터치 체크**
- 당일 예약 현황 한눈에 확인
- 블랙 처리 시 고객DB에 **자동 태그**

### 5. 어디에도 기록이 남지 않습니다

예약과 출퇴근 정보는 **서버에 저장하지 않습니다.**

- 앱 실행 중에만 메모리에서 운영
- 앱을 종료하면 **자동으로 완전 소멸**
- 서버에 업무 기록이 없으므로 **서버가 털려도 안전**
- 금액 정보를 저장하지 않음
- **장부가 남지 않는 깨끗한 운영**

### 6. 텔레그램 채널 자동 홍보

출근 등록이 끝나면 **한 번의 터치**로:

> 🏠 **[업소명] 오늘의 출근부**
>
> ✅ 김OO 관리사 (10:00~)
> ✅ 이OO 관리사 (11:00~)
> ✅ 박OO 관리사 (10:00~)
>
> 📞 예약문의: 010-XXXX-XXXX

매일 수작업으로 작성할 필요 없이, 텔레그램 채널에 **자동 전송**됩니다.

## 주요 기능 한눈에

| 기능 | 설명 |
|------|------|
| 스마트 전화 | 수신 전화 시 고객 정보 즉시 확인 |
| 고객DB 공유 | 사용자 간 블랙/진상/콜폭/타업소 정보 공유 |
| 빠른 등록 | 최근 통화기록에서 바로 고객 정보 등록 |
| 원터치 예약 | 통화기록에서 바로 예약 등록 |
| 관리사 관리 | 사진 등록, 출퇴근 체크, 스케줄 확인 |
| 예약 현황 | 당일 관리사별 예약 타임라인 |
| 기록 제로 | 예약/출퇴근 서버 미저장, 앱 종료 시 소멸 |
| 자동 홍보 | 텔레그램 채널 출근부 자동 전송 |
| 블랙 자동 기록 | 블랙 처리 시 고객DB에 자동 태그 |

## 화면 구성

```
[전화]  [최근기록]  [검색]  [업장관리]  [설정]
```

- **전화** — 기본 전화앱 (수신 시 고객 정보 표시, 다이얼 패드)
- **최근기록** — 통화 기록 + 태그 표시 + 예약 등록
- **검색** — 번호로 고객 검색 + [추가] 버튼으로 빠른 등록
- **업장관리** — 업소 정보, 관리사, 코스, 출퇴근, 예약 현황
- **설정** — 텔레그램 연동, 알림, 계정

---

## 이렇게 사용합니다

```
1. 앱 설치 (APK)
2. 앱 실행 시 자동으로 전화번호 인증
3. 관리자 승인 후 사용 시작
4. 기본 전화앱으로 설정
5. 업장 정보 + 관리사 + 코스 등록
6. 텔레그램 채널 연동
7. 바로 사용!
```

## 보안

- 예약/출퇴근 데이터는 **서버에 저장하지 않음** (앱 메모리에서만 운영)
- 앱 종료 시 업무 데이터 **자동 소멸**, 포렌식 복구 불가
- 금액 정보 미저장 — 장부 기록 없음
- 고객 전화번호 암호화 저장
- 앱 코드 난독화 + 위변조 방지
- 모든 통신 HTTPS 암호화

## 왜 콜가드인가?

| | 기존 방식 | 콜가드 |
|---|---|---|
| 고객 확인 | 전화 받아봐야 안다 | **받기 전에 안다** |
| 블랙 대응 | 당한 후 기억에 의존 | **자동 기록 + 공유** |
| 타업소 확인 | 누군지 모른다 | **태그로 즉시 확인** |
| 예약 관리 | 메모장 / 머릿속 | **앱에서 원터치** |
| 업무 기록 | 장부에 남아 부담 | **기록 없음, 자동 소멸** |
| 출근부 | 매일 수작업 작성 | **자동 생성 + 전송** |
| 홍보 | 직접 채널에 글 작성 | **버튼 한 번이면 끝** |
